# 🇳🇬 Civics Quiz Game

An interactive Nigerian Civics Quiz Game designed to help users test and improve their knowledge of Civic Education, Nigeria, and responsible citizenship.

## 🎯 Features

- 🎯 10 Civic Education questions
- ⏱️ 20-second timer
- 📊 Score and percentage system
- 🏆 Civic Level
- 🥇 Grade system
- 🏅 Best Score
- 📈 Progress bar
- 📱 Mobile responsive design
- 🎉 Result animation and confetti
- 👤 Player name display

## 🛠️ Technologies

- HTML
- CSS
- JavaScript
